## Important: no public API

Limehome does **not** publish a developer program. There is no developer portal, no API documentation, no machine-readable specification, and no client SDK for Limehome's own services.

A production API host exists at `https://api.limehome.com` (AWS API Gateway behind CloudFront), but it is a first-party/private backend for Limehome's own web and mobile clients. Probed on 2026-07-19, every discovery path returned either a catch-all `{"message": "Welcome to Limehome API"}` body or an AWS WAF 401 stating "This url is intended to be used only from specific sources". Do not represent this host as a consumable public API, and do not attempt to generate integration code against it.

If you need programmatic access to Limehome inventory, the documented route is a commercial conversation, not self-service onboarding — see the contact surfaces below.
